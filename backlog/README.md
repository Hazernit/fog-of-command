# Backlog и Issue IDs

**Статус:** задачи подготовлены локально, но ещё не опубликованы на GitHub. Сами Issues можно создать из `scripts/publish_github.py`.

## Приоритеты

`P0`: блокирует исходный прототип; `P1`: следует после доказательства основных систем; `P2`: эксперимент/отдалённый этап, пока не брать в разработку.

## Правило изменения backlog

Владелец может закрывать/менять GitHub Issues в любой момент. Локальные файлы — исходный набор для первоначальной публикации, **не** автоматический источник повторной перезаписи уже отредактированных задач. Скрипт пропускает существующие Issue IDs и ничего не удаляет.
