**Этап:** S0 — Foundation / technical baseline  
**Приоритет:** P0  
**Область:** tooling  
**Зависит от:** Нет (можно начинать после готовности общего окружения).

## Зачем
Создать воспроизводимую среду UE без догадок о версии и аппаратной стабильности.

## Scope / что сделать
Проверить доступную стабильную UE 5.x, Visual Studio/C++ toolchain, запуск пустого проекта в editor/PIE; отдельно проверить стабильность GPU/драйверов Windows. Записать конфигурацию и процедуру чистого запуска в docs/ENGINE_VERSION.md.

## Критерии приёмки
- [ ] Указана конкретная версия UE, IDE, SDK и компилятора
- [ ] Чистый тестовый Unreal C++ проект открывается и запускается в PIE на Windows
- [ ] Документированы команды, фактические результаты, длительность компиляции и известные проблемы GPU
- [ ] При сбоях железа создан отдельный блокер, без ложного вывода о баге Unreal

## Проверка (Codex / разработчик)
Ручной smoke на Windows; скрин/логи Editor и версия движка. Никакого PASS без запуска.

## Не входит
Реализация соседних этапов и несвязанных систем.

## Передача Codex
1. Прочитать `AGENTS.md`, `docs/ARCHITECTURE.md` и эту Issue.
2. Проверить зависимости выше. Открыть ветку `feat/foc-001-short-topic` или `docs/...`.
3. Реализовать **только этот scope**, добавить тесты и открыть PR; не пушить напрямую в `main`.
4. В PR предоставить реальные результаты проверок и явно отметить `NOT RUN`, если нет среды UE.

**Acceptance:** [ ] PR проверен владельцем; [ ] критерии выше подтверждены; [ ] без нарушений UnitId/WorldState/PerceivedWorldState.
