**Этап:** S1 — RTS tactical loop  
**Приоритет:** P0  
**Область:** assets  
**Зависит от:** `FOC-004`, `FOC-002`

## Зачем
Получить видимый набор для игрового эксперимента.

## Scope / что сделать
Две условные фракции, пехота, бронетехника, разведывательный дрон и машина снабжения как placeholders. Сторона/типы связываются с UnitId.

## Критерии приёмки
- [ ] В сцене есть несколько юнитов каждой стороны и разных классов
- [ ] Силуэты/иконки читаемы с RTS масштаба
- [ ] Принадлежность единиц хранится в WorldState
- [ ] Нет коммерческих моделей без подтверждённой лицензии

## Проверка (Codex / разработчик)
PIE расстановка юнитов, тест идентификаторов и удаления.

## Не входит
Реализация соседних этапов и несвязанных систем.

## Передача Codex
1. Прочитать `AGENTS.md`, `docs/ARCHITECTURE.md` и эту Issue.
2. Проверить зависимости выше. Открыть ветку `feat/foc-012-short-topic` или `docs/...`.
3. Реализовать **только этот scope**, добавить тесты и открыть PR; не пушить напрямую в `main`.
4. В PR предоставить реальные результаты проверок и явно отметить `NOT RUN`, если нет среды UE.

**Acceptance:** [ ] PR проверен владельцем; [ ] критерии выше подтверждены; [ ] без нарушений UnitId/WorldState/PerceivedWorldState.
