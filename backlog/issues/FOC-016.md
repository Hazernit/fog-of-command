**Этап:** S2 — Intelligence / Fog of War  
**Приоритет:** P0  
**Область:** intel  
**Зависит от:** `FOC-004`, `FOC-012`

## Зачем
Реализовать техническую границу между реальностью и разведданными.

## Scope / что сделать
У каждой стороны свой список видимых своих юнитов и наблюдений о врагах; UI получает данные через строго ограниченный facade. Не отправлять hidden targets в список видимых объектов.

## Критерии приёмки
- [ ] Незамеченный противник отсутствует в PerceivedWorldState и публичном UI API
- [ ] Состояния противоположных фракций различаются
- [ ] После исчезновения объекта из сенсора данные становятся контактом, а не live transform
- [ ] Есть тесты на отсутствие утечки координат

## Проверка (Codex / разработчик)
Автоматические проверки 2 фракций, debug QA просмотр обоих states.

## Не входит
Реализация соседних этапов и несвязанных систем.

## Передача Codex
1. Прочитать `AGENTS.md`, `docs/ARCHITECTURE.md` и эту Issue.
2. Проверить зависимости выше. Открыть ветку `feat/foc-016-short-topic` или `docs/...`.
3. Реализовать **только этот scope**, добавить тесты и открыть PR; не пушить напрямую в `main`.
4. В PR предоставить реальные результаты проверок и явно отметить `NOT RUN`, если нет среды UE.

**Acceptance:** [ ] PR проверен владельцем; [ ] критерии выше подтверждены; [ ] без нарушений UnitId/WorldState/PerceivedWorldState.
