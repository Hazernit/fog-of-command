**Этап:** S0 — Foundation / technical baseline  
**Приоритет:** P0  
**Область:** core  
**Зависит от:** `FOC-004`

## Зачем
Подготовить единый понятный контракт приказов для игрока и ИИ.

## Scope / что сделать
Добавить структуру Command/Order и состояния Pending/Executing/Completed/Cancelled/Failed; первыми типами MOVE/HOLD, остальные расширяем через data model. Не писать весь ИИ.

## Критерии приёмки
- [ ] Один актуальный исполняемый приказ на юнит (если иной дизайн не согласован)
- [ ] Приказы имеют устойчивые IDs, временные метки и причину отказа
- [ ] Переключение контроллера не уничтожает приказ без явно описанного правила
- [ ] Состояния приказов тестируются без обязательного UI

## Проверка (Codex / разработчик)
Тесты смены приказа, отмены, отсутствующего UnitId, некорректных параметров.

## Не входит
Реализация соседних этапов и несвязанных систем.

## Передача Codex
1. Прочитать `AGENTS.md`, `docs/ARCHITECTURE.md` и эту Issue.
2. Проверить зависимости выше. Открыть ветку `feat/foc-005-short-topic` или `docs/...`.
3. Реализовать **только этот scope**, добавить тесты и открыть PR; не пушить напрямую в `main`.
4. В PR предоставить реальные результаты проверок и явно отметить `NOT RUN`, если нет среды UE.

**Acceptance:** [ ] PR проверен владельцем; [ ] критерии выше подтверждены; [ ] без нарушений UnitId/WorldState/PerceivedWorldState.
