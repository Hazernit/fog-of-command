**Приоритет:** P0  
**Область:** core  
**Зависит от:** `FOC-002`

## Зачем
Ввести единый контракт состояния для RTS/FPS и будущих сохранений.

## Scope / что сделать
Реализовать минимальные типы UnitId, SideId, UnitState, OrderId с проверками валидности, здоровья, боезапаса и жив/уничтожен. По возможности вынести тестируемую логику из Actor Tick.

## Критерии приёмки
- [ ] UnitId уникален и сохраняется при переходах состояния
- [ ] Создание/удаление объектов идемпотентно по контракту
- [ ] Невозможные отрицательные запасы/health обрабатываются явно
- [ ] Есть тесты жизненного цикла и сериализуемых типов

## Проверка (Codex / разработчик)
Automation/Unit tests на создание, перемещение, повреждение, уничтожение; лог инвариантов.

## Не входит
Реализация соседних этапов и несвязанных систем.

## Передача Codex
1. Прочитать `AGENTS.md`, `docs/ARCHITECTURE.md` и эту Issue.
2. Проверить зависимости выше. Открыть ветку `feat/foc-004-short-topic` или `docs/...`.
3. Реализовать **только этот scope**, добавить тесты и открыть PR; не пушить напрямую в `main`.
4. В PR предоставить реальные результаты проверок и явно отметить `NOT RUN`, если нет среды UE.
