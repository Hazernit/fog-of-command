## Зачем
Сделать информацию результатом действий, а не всезнания.

## Scope / что сделать
Сенсоры с радиусом, углом обзора, LOS препятствиями, частотой проверок. Производить событие Observation для найденных единиц без бесконечного трассинга каждый кадр.

## Критерии приёмки
- [ ] Объект за укрытием недоступен сенсору по правилам
- [ ] Обнаружение появляется/исчезает при входе/выходе из зоны
- [ ] Расход проверки сенсоров измерим и ограничен
- [ ] Сенсор не обновляет чужую сторону

## Проверка (Codex / разработчик)
PIE геометрические тесты радиуса/LOS; измерить число traces/sec.

## Не входит
Реализация соседних этапов и несвязанных систем.
