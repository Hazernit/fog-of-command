**Зависит от:** `FOC-031`

## Зачем
Решить, жизнеспособна ли отдельная мобильная адаптация.

## Scope / что сделать
Короткая карта, 3 канала давления, несколько отрядов, один сенсор, touch controls; проверить производительность в отдельной конфигурации UE.

## Критерии приёмки
- [ ] Формат отличается от сложного PC UI
- [ ] Нет скрытых pay-to-win преимуществ
- [ ] Получены фактические FPS/память хотя бы на одном реальном устройстве
- [ ] Есть UX/экономическая оценка: выпускать или нет

## Проверка (Codex / разработчик)
Тест на целевом устройстве + playtest 5–10 минут; итоги в ADR.

## Не входит
Реализация соседних этапов и несвязанных систем.

## Передача Codex
1. Прочитать `AGENTS.md`, `docs/ARCHITECTURE.md` и эту Issue.
2. Проверить зависимости выше. Открыть ветку `feat/foc-043-short-topic` или `docs/...`.
3. Реализовать **только этот scope**, добавить тесты и открыть PR; не пушить напрямую в `main`.
4. В PR предоставить реальные результаты проверок и явно отметить `NOT RUN`, если нет среды UE.

**Acceptance:** [ ] PR проверен владельцем; [ ] критерии выше подтверждены; [ ] без нарушений UnitId/WorldState/PerceivedWorldState.
