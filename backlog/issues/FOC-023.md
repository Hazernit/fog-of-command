**Этап:** S3 — Direct Control / Logistics / MVP  
**Приоритет:** P1  
**Область:** controls  
**Зависит от:** `FOC-004`, `FOC-011`, `FOC-021`

## Зачем
Переводить управление на существующую сущность без телепорта/копии.

## Scope / что сделать
Механизм входа/выхода RTS player controller → controllable Pawn/possess → RTS, с сохранением UnitId, health, resource state, active order.

## Критерии приёмки
- [ ] Переход не дублирует UnitId/Actor/ресурсы
- [ ] Вход/выход не восстанавливает здоровье, боезапас или топливо
- [ ] Смерть объекта во время ручного управления возвращает в RTS с сообщением
- [ ] Проверено не менее 50 циклов переключения

## Проверка (Codex / разработчик)
Автотест инвариантов + PIE 50 toggles при активных других юнитах.

## Не входит
Реализация соседних этапов и несвязанных систем.
