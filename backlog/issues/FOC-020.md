## Зачем
Сделать неопределённость понятной и наглядной.

## Scope / что сделать
Показ тумана войны, локализации/радиуса контакта, источника, давности, статуса подтверждения. Не отображать истинный health/transform врага.

## Критерии приёмки
- [ ] Скрытый враг не рисуется на карте/изображении до наблюдения
- [ ] Индикатор показывает источник/давность/неопределённость
- [ ] Данные подходят для дальтоников: цвет+иконка/текст
- [ ] Нет UI binding к true hidden coordinates

## Проверка (Codex / разработчик)
Ручной UX сценарий: дрон видит цель → контакт устаревает → цель исчезает из видимости.

## Не входит
Реализация соседних этапов и несвязанных систем.

## Передача Codex
1. Прочитать `AGENTS.md`, `docs/ARCHITECTURE.md` и эту Issue.

4. В PR предоставить реальные результаты проверок и явно отметить `NOT RUN`, если нет среды UE.
