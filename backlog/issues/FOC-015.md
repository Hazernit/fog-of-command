Сделать первый связный сценарий вместо бессрочной песочницы.

Одна карта с 2-3 контрольными точками, таймер/счёт, простые правила победы/поражения и restart. Визуализация состояния целей.

## Критерии приёмки
- [ ] Матч начинается из меню/сцены без консольных команд
- [ ] Можно победить и проиграть предсказуемо
- [ ] Перезапуск сбрасывает состояние без дублей
- [ ] Описан один воспроизводимый сценарий для ручного тестирования

## Проверка (Codex / разработчик)
2 прогона: победа и поражение; полная очистка состояния после restart.
