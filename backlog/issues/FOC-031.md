## Зачем
Решить по факту, стоит ли продолжать проект до кампании.

## Scope / что сделать
Запуск сценария с 12–24 условными юнитами на Windows i9-9900K/RTX4070/64GB; замер FPS/AI/sensor costs, crash-free run, набор воспроизводимых багов и внешний плейтест-план.

## Критерии приёмки
- [ ] 30 минут без критического падения UE/игры на стабильном ПК
- [ ] Фактический FPS и профиль затрат CPU/GPU/сенсоров записаны
- [ ] Пройдены инварианты state, possession, save, fog, resources
- [ ] Список блокеров и критерии Go/No-Go для кампании принят владельцем

## Проверка (Codex / разработчик)
Видео/скрин профайлера, релизный чеклист и ссылки на тест-логи; без выдуманных цифр.

## Не входит
Реализация соседних этапов и несвязанных систем.

## Передача Codex
1. Прочитать `AGENTS.md`, `docs/ARCHITECTURE.md` и эту Issue.
2. Проверить зависимости выше. Открыть ветку `feat/foc-031-short-topic` или `docs/...`.
3. Реализовать **только этот scope**, добавить тесты и открыть PR; не пушить напрямую в `main`.
4. В PR предоставить реальные результаты проверок и явно отметить `NOT RUN`, если нет среды UE.

**Acceptance:** [ ] PR проверен владельцем; [ ] критерии выше подтверждены; [ ] без нарушений UnitId/WorldState/PerceivedWorldState.
