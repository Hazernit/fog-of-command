**Этап:** S0 — Foundation / technical baseline  
**Приоритет:** P0  
**Область:** core  
**Зависит от:** `FOC-004`, `FOC-005`

## Зачем
Подготовить основу согласованности между боем и будущей кампанией.

## Scope / что сделать
Версионируемый snapshot для UnitId, основных ресурсов, жив/уничтожен, текущего приказа и времени симуляции. Документировать ограничения формата и поведение при несовместимой версии.

## Критерии приёмки
- [ ] Round-trip save/load восстанавливает одни и те же UnitIds, значения и приказы
- [ ] Нет дублирования объектов после повторной загрузки
- [ ] Повреждённый/неизвестный формат даёт явную ошибку
- [ ] Есть набор автоматических тестов совместимости v1

## Проверка (Codex / разработчик)
Автотесты encode/decode и повторной загрузки; ручная проверка в минимальной карте.

## Не входит
Реализация соседних этапов и несвязанных систем.

## Передача Codex
1. Прочитать `AGENTS.md`, `docs/ARCHITECTURE.md` и эту Issue.
2. Проверить зависимости выше. Открыть ветку `feat/foc-007-short-topic` или `docs/...`.
3. Реализовать **только этот scope**, добавить тесты и открыть PR; не пушить напрямую в `main`.
4. В PR предоставить реальные результаты проверок и явно отметить `NOT RUN`, если нет среды UE.

**Acceptance:** [ ] PR проверен владельцем; [ ] критерии выше подтверждены; [ ] без нарушений UnitId/WorldState/PerceivedWorldState.
