## Зачем
Сделать проверку изменений воспроизводимой для Codex и разработчика.

## Scope / что сделать
Добавить минимальный Unreal automation smoke-test, руководство запуска из терминала, начальный Windows CI (с учётом наличия runner/UE) либо честно помеченный manual gate, PR checklist.

## Критерии приёмки
- [ ] Есть как минимум один проходящий Automation Test в реальном Unreal
- [ ] Команды запуска записаны и воспроизводимы
- [ ] Где UE CI недоступен, workflow не маскируется как зелёная сборка UE
- [ ] PR template фиксирует PASS/FAIL/NOT RUN и доказательства

## Проверка (Codex / разработчик)
Запустить тест на Windows; если CI невозможен, CI docs не выдаются за UE-test.

## Не входит
Реализация соседних этапов и несвязанных систем.

## Передача Codex
1. Прочитать `AGENTS.md`, `docs/ARCHITECTURE.md` и эту Issue.
2. Проверить зависимости выше. Открыть ветку `feat/foc-003-short-topic` или `docs/...`.
3. Реализовать **только этот scope**, добавить тесты и открыть PR; не пушить напрямую в `main`.
4. В PR предоставить реальные результаты проверок и явно отметить `NOT RUN`, если нет среды UE.

**Acceptance:** [ ] PR проверен владельцем; [ ] критерии выше подтверждены; [ ] без нарушений UnitId/WorldState/PerceivedWorldState.
