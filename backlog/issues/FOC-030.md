**Приоритет:** P1  
**Область:** ui  
**Зависит от:** `FOC-015`, `FOC-022`, `FOC-027`, `FOC-029`

## Зачем
Дать игроку объяснение последствий и пользу от ошибочной информации.

## Scope / что сделать
Экран итога победы/поражения, потерь/расходов, истории контактов, post-match раскрытия реальной карты как режима разбора, не во время матча.

## Критерии приёмки
- [ ] Есть результаты для обеих сторон
- [ ] Разница реальных и воспринимаемых контактов видна только после матча
- [ ] Журнал событий не требует подключения к внешнему сервису
- [ ] Экран повторяем после save/load по принятой модели

## Проверка (Codex / разработчик)
Два матча с различными разведданными, проверка послематчевого раскрытия.

## Не входит
Реализация соседних этапов и несвязанных систем.

## Передача Codex
1. Прочитать `AGENTS.md`, `docs/ARCHITECTURE.md` и эту Issue.
2. Проверить зависимости выше. Открыть ветку `feat/foc-030-short-topic` или `docs/...`.
3. Реализовать **только этот scope**, добавить тесты и открыть PR; не пушить напрямую в `main`.
4. В PR предоставить реальные результаты проверок и явно отметить `NOT RUN`, если нет среды UE.

**Acceptance:** [ ] PR проверен владельцем; [ ] критерии выше подтверждены; [ ] без нарушений UnitId/WorldState/PerceivedWorldState.
