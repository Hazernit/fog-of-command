**Зависит от:** `FOC-001`

## Зачем
Получить воспроизводимый проект, который можно клонировать и открыть в UE.

## Scope / что сделать
Создать `FogOfCommand.uproject`, модуль C++, базовый GameMode, минимальную сцену из примитивов. Использовать точную версию из FOC-001. Проверить Git LFS до добавления uasset/umap.

## Критерии приёмки
- [ ] Есть `.uproject`, базовый исходный код и минимальная карта
- [ ] С нуля из git clone проект открывается на Windows без файлов Saved/Binaries/Intermediate
- [ ] PIE запускается, есть старт/выход без fatal ошибок
- [ ] В Git не попали Generated кеши или нелицензированные ассеты

## Проверка (Codex / разработчик)
Чистый checkout → открыть UE → собрать C++ → Play In Editor. Задокументировать точные шаги.

## Не входит
Реализация соседних этапов и несвязанных систем.

## Передача Codex
1. Прочитать `AGENTS.md`, `docs/ARCHITECTURE.md` и эту Issue.
2. Проверить зависимости выше. Открыть ветку `feat/foc-002-short-topic` или `docs/...`.
3. Реализовать **только этот scope**, добавить тесты и открыть PR; не пушить напрямую в `main`.
4. В PR предоставить реальные результаты проверок и явно отметить `NOT RUN`, если нет среды UE.

**Acceptance:** [ ] PR проверен владельцем; [ ] критерии выше подтверждены; [ ] без нарушений UnitId/WorldState/PerceivedWorldState.
