# Ассеты

Здесь пока **нет** графики и сторонних файлов. В MVP используются собственные placeholders (кубы, капсулы) и материалы с проверенной лицензией.

Для каждого внешнего ассета фиксируем: название, источник/URL, автор, лицензию, разрешённые способы распространения, условия attribution и факт использования генеративных инструментов при необходимости.

Перед добавлением Unreal `.uasset/.umap` нужно установить Git LFS; `.gitattributes` уже содержит базовые шаблоны.
