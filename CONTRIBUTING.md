# Contributing / правила работы

Проект пока находится в pre-production. Перед первым PR прочитайте `AGENTS.md` и соответствующую Issue.

## Branch/PR

- Ветка от `main`: `feat/foc-###-short-name` или `docs/foc-###-short-name`.
- Одна Issue — один PR; не совмещать рефакторинг чужого кода и новую механику.
- Указать скриншоты/видео, когда меняется интерфейс или геймплей.
- Не заявлять прохождение тестов, которые не запускались.
- Не коммитить файлы Unreal Cache/Intermediate/Binaries/Saved и лицензируемые ассеты без проверки прав.

## Тесты

Документация/структура: `python scripts/validate_backlog.py`.
UE-код: проверки из конкретной Issue + сборка, Automation Tests и ручной smoke при наличии UE. До установки Unreal все UE-тесты честно помечаются `NOT RUN`.

## Графика/лицензии

Любой внешний ассет требует указания автора, URL/источника, лицензии, ограничений на перераспространение и использования ИИ, если применимо. Не использовать материалы, извлечённые из коммерческих игр без разрешения.

## Приёмка

Владелец проекта принимает архитектурные решения и мерджит основной код после проверок. AGENTS.md — обязательные правила для автоматизированных исполнителей.
